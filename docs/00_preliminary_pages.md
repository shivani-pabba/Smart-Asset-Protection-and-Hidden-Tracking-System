## ABSTRACT

The rapid proliferation of valuable personal, commercial, and institutional mobile assets—including computing equipment, corporate travel luggage, high-value tools, and vital documentation—has exacerbated the problem of accidental loss, displacement, and theft. Conventional asset management practices rely heavily upon passive visual tagging, static barcode or QR-code scanning, or bulky proprietary tracking units that require recurring cellular subscription fees and separate, fragmented mobile utilities. 

To overcome these challenges, this capstone project designs, develops, and evaluates the **Smart Asset Protection and Hidden Tracking System**, an integrated mobile and cloud platform that unifies digital asset inventory management, smartphone Global Positioning System (GPS) monitoring, Bluetooth Low Energy (BLE) scanning, Received Signal Strength Indicator (RSSI) proximity estimation, dynamic geofencing, and automated security alert dispatching into a cohesive architectural ecosystem.

The system is engineered as a decoupled, multi-tier full-stack application. The client frontend is developed using **Flutter and Dart**, delivering cross-platform performance across Android and iOS with native device integration. The backend service is constructed using **Node.js and Express.js**, providing scalable RESTful APIs for asset state handling, geofence updates, and security alert aggregation. Persistent data storage is managed via **MongoDB**, leveraging flexible NoSQL document schemas for assets, historical spatial coordinates, and alert records. 

Device-level localization and proximity monitoring operate across two distinct technological paradigms:
1. **Smartphone GPS Monitoring**: Utilizes the device's integrated GNSS receiver via the `geolocator` package to continuously record host coordinates, track geofenced safe-zone adherence using spherical distance calculations (Haversine formulation), and detect perimeter breaches.
2. **Bluetooth Low Energy (BLE) Proximity Sensing**: Utilizes the `flutter_blue_plus` framework to scan for nearby advertising BLE peripherals and tracking beacons. The system evaluates real-time Received Signal Strength Indicator (RSSI) values in decibels relative to one milliwatt (dBm), translating measured signal attenuation into qualitative proximity tiers (Immediate, Near, Far, and Out-of-Range) via logarithmic distance models.

A fundamental academic distinction maintained throughout this project is that smartphone GPS monitors the position of the mobile device itself, whereas autonomous, independent tracking of physical assets requires paired compatible BLE beacons or dedicated satellite hardware. The prototype implements robust error handling, offline data caching via `shared_preferences`, de-duplication of security alerts within time windows, and a transparent simulation mode for academic evaluation. Extensive functional, integration, database, and hardware sensor testing validates that the proposed system delivers a reliable, responsive, and intuitive foundation for modern mobile asset protection.

**Keywords:** Smart Asset Protection, Bluetooth Low Energy (BLE), Received Signal Strength Indicator (RSSI), Global Positioning System (GPS), Geofencing, Flutter, Node.js, Express.js, MongoDB, Mobile Security.
